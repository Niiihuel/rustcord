The illustrations of Discord's empty states, as its web client serves them
(authorized by the owner on 2026-11-08; see `AGENTS.md`), drawn from their
SVGs at twice the size Discord shows them, with
`rsvg-convert -w W -h H source.svg -o name.png` and stripped. `-dark` and
`-light` are Discord's versions for each theme. Where each comes from and
where it is shown: «Empty-state illustrations» in `docs/discord-reference.md`.
`rustcord_components::illustration` embeds them.
